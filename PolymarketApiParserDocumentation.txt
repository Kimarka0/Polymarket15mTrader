🎯 Общее описание системы
Что делает система?
Это автоматический мониторинг 15-минутных BTC рынков на платформе Polymarket. Система:

Находит активные 15-минутные рынки "Bitcoin Up/Down"

Определяет цену BTC на момент начала рынка (priceToBeat)

Отслеживает изменение цены в реальном времени

Автоматически переходит к следующему рынку каждые 15 минут

Отображает все данные в пользовательском интерфейсе

Основная проблема, которую решает система
API Polymarket возвращает некорректные даты начала и окончания рынков. Например:

startDate: 2026-01-14T09:53:32.526383Z (14 января)

endDate: 2026-01-15T10:00:00Z (15 января)

Это приводит к неправильному определению длительности рынка и, как следствие, к неверному расчету priceToBeat (разница в $1800+ за 8 минут).

Решение: Система игнорирует даты от API и самостоятельно рассчитывает 15-минутные интервалы на основе текущего времени.

🔍 FindActive15MinuteBtcMarket()
Что делает: Ищет активный 15-минутный BTC рынок.

csharp
public IEnumerator FindActive15MinuteBtcMarket(Action<PolymarketEvent> onSuccess, Action<string> onError)
{
    Debug.Log("[MarketSearch] Starting search for active 15-minute BTC market");
    yield return StartCoroutine(SearchByGeneratedSlug(onSuccess, onError));
}
Как работает:

Логирует начало поиска

Вызывает SearchByGeneratedSlug() - первую стратегию поиска

Использует IEnumerator и yield return для асинхронной работы

Почему IEnumerator?
Unity использует корутины (coroutines) для асинхронных операций. IEnumerator позволяет "приостанавливать" выполнение метода, ждать ответа от API, а потом продолжать.

Подробнее о slug:
Slug - это часть URL, которая идентифицирует ресурс. Например:
https://polymarket.com/event/btc-updown-15m-1705240800
Здесь btc-updown-15m-1705240800 - slug рынка.

Генерация timestamp:

csharp
private string GetCurrent15MinTimestamp()
{
    DateTime now = DateTime.UtcNow;
    long unixTimestamp = ((DateTimeOffset)now).ToUnixTimeSeconds();
    long fifteenMinBlocks = unixTimestamp / 900;  // 900 секунд = 15 минут
    long currentBlockTimestamp = fifteenMinBlocks * 900;
    
    return currentBlockTimestamp.ToString();
}
Пример: Если сейчас 10:07:30, то:

Unix время: 1705241250 секунд

Делим на 900: 1705241250 / 900 = 1894712 (целочисленное деление)

Умножаем обратно: 1894712 * 900 = 1705240800

Это соответствует времени 10:00:00

💰 GetPriceAtMarketStart()
Что делает: Получает цену BTC на момент начала рынка.

csharp
public IEnumerator GetPriceAtMarketStart(DateTime marketStartTime, Action<double> onSuccess, Action<string> onError)
{
    Debug.Log($"[PriceFetch] Requesting BTC price at market start: {marketStartTime:HH:mm:ss}");
    
    // Try to get exact historical price
    yield return StartCoroutine(GetExactHistoricalPrice(marketStartTime, 
        onSuccess: (price) => {
            onSuccess?.Invoke(price);
        },
        onError: (error) => {
            Debug.Log($"[PriceFetch] Historical price failed: {error}, trying fallback...");
            // Fallback to current price if historical fails
            StartCoroutine(GetCurrentBTCPrice(onSuccess, onError));
        }
    ));
}
Архитектурный паттерн: Callback functions (Action<>)
Вместо возврата значения напрямую, метод принимает две функции:

onSuccess - что делать при успехе

onError - что делать при ошибке

Это стандартный подход в асинхронном программировании Unity.

    using (UnityWebRequest request = UnityWebRequest.Get(url))

        yield return request.SendWebRequest();
        
        if (request.result != UnityWebRequest.Result.Success)
        {
            Debug.LogWarning($"[PriceFetch] Failed to get exact candle: {request.error}");
            onError?.Invoke("Failed to fetch historical price");
            yield break;
        }
        
        string json = request.downloadHandler.text;
        
        // ... парсинг ответа ...
    }
}
Что такое Klines?
Klines (или свечи) - это формат данных биржи, который содержит:

Время открытия свечи

Цену открытия (Open)

Максимальную цену (High)

Минимальную цену (Low)

Цену закрытия (Close)

Объем торгов

Пример ответа Binance:

json
[

    "95050.00",         // High
    "94980.00",         // Low
    "95025.00",         // Close
    "15.256",           // Volume
    1705240859999,      // Close time
    "1448925.00",       // Quote asset volume
    100,                // Number of trades
    "5.256",            // Taker buy base asset volume
    "6.256",            // Taker buy quote asset volume
    "0"                 // Ignore
  ]
]
Почему округляем до начала минуты?
Binance хранит данные по 1-минутным свечам, которые начинаются на :00 каждой минуты. Если рынок начался в 09:53:32, мы ищем свечу, которая началась в 09:53:00.

🎮 MarketController - бизнес-логика
Назначение
Это мозг системы. Он координирует все остальные компоненты, управляет состоянием и переходами между рынками.

Ключевые поля (переменные класса)
csharp
private bool isTrading = false;           // Флаг: идет ли сейчас мониторинг
private int currentMarketId = 0;          // ID текущего рынка (для предотвращения конфликтов)
private Coroutine marketSearchCoroutine;  // Ссылка на корутину поиска рынка
private Coroutine dataUpdateCoroutine;    // Ссылка на корутину обновления данных
private Coroutine marketResetCoroutine;   // Ссылка на корутину принудительного сброса
Почему три корутины?
Каждая корутина отвечает за свой процесс:

marketSearchCoroutine - поиск и настройка рынков

dataUpdateCoroutine - обновление данных раз в секунду

marketResetCoroutine - принудительный сброс каждые 15 минут

Основной жизненный цикл
🚀 StartMonitoring() - запуск системы
csharp
public void StartMonitoring()
{
    if (isTrading) return;  // Уже работает? Не запускаем повторно
    
    Debug.Log("[MarketController] Starting market monitoring");
    isTrading = true;
    currentMarketId++;  // Увеличиваем ID для нового запуска
    
    // Запускаем 15-минутный цикл принудительного сброса
    StartMarketResetCycle();
    
    // Начинаем поиск рынка
    marketSearchCoroutine = StartCoroutine(FindAndSetupMarket());
}
Важность currentMarketId:
Представьте, что старый рынок еще завершается, а мы уже начали искать новый. currentMarketId помогает отслеживать, какой рынок сейчас актуален.

🔄 FindAndSetupMarket() - основной цикл поиска
csharp
private IEnumerator FindAndSetupMarket()
{
    while (isTrading)  // Пока пользователь не остановит мониторинг
    {
        searchCount++;
        int thisMarketId = currentMarketId;  // Запоминаем ID этого поиска
        
        Debug.Log($"[MarketController] Market search (attempt #{searchCount}, market #{thisMarketId})");
        
        // 1. Ищем рынок через ApiManager
        PolymarketEvent foundMarket = null;
        bool searchCompleted = false;
        
        yield return StartCoroutine(apiManager.FindActive15MinuteBtcMarket(
            onSuccess: (market) => {
                foundMarket = market;
                searchCompleted = true;
            },
            onError: (error) => {
                searchCompleted = true;
            }
        ));
        
        // 2. Если не нашли реальный рынок → тестовый
        if (foundMarket == null && isTrading)
        {
            Debug.Log("[MarketController] Using test market");
            foundMarket = apiManager.GetTestMarket();
        }
        
        // 3. Если нашли рынок И это еще актуальный поиск
        if (foundMarket != null && isTrading && thisMarketId == currentMarketId)
        {
            // Настраиваем рынок
            yield return StartCoroutine(SetupMarketWithHistoricalPrice(foundMarket));
            
            // Ждем, пока рынок активен
            while (marketState.IsMarketActive() && isTrading && thisMarketId == currentMarketId)
            {
                yield return new WaitForSeconds(1f);  // Проверяем каждую секунду
            }
            
            // 4. Рынок завершился
            if (isTrading && thisMarketId == currentMarketId)
            {
                OnMarketCompleted();  // Логируем результаты
                
                // Ждем перед поиском следующего
                yield return new WaitForSeconds(marketSearchDelay);
            }
        }
    }
}
Ключевые проверки:

isTrading - пользователь еще не остановил мониторинг?

thisMarketId == currentMarketId - это все еще актуальный рынок?

🔄 DataUpdateLoop() - цикл обновления данных
csharp
private IEnumerator DataUpdateLoop()
{
    Debug.Log("[MarketController] Starting data updates");
    
    int updateCount = 0;
    
    while (marketState.IsMarketActive() && isTrading)
    {
        updateCount++;
        
        // Каждые 30 обновлений (30 секунд) логируем время
        if (updateCount % 30 == 0)
        {
            int secondsRemaining = marketState.GetSecondsRemaining();
            Debug.Log($"[MarketController] Update #{updateCount}, Time remaining: {secondsRemaining / 60}:{secondsRemaining % 60:D2}");
        }
        
        // 1. Получаем текущую цену BTC
        yield return StartCoroutine(apiManager.GetCurrentBTCPrice(
            onSuccess: (price) => marketState.UpdateCurrentPrice(price),
            onError: (error) => Debug.Log($"[MarketController] Price update error: {error}")
        ));
        
        // 2. Генерируем тестовые данные стакана
        marketState.GenerateTestOrderbookData();
        marketState.GenerateTestVolume();
        
        // 3. Обновляем UI
        UpdateUI();
        
        // 4. Ждем 1 секунду до следующего обновления
        yield return new WaitForSeconds(updateInterval);
    }
}
Что такое "стакан заявок" (orderbook)?
Это список всех заявок на покупку (bid) и продажу (ask) с указанием цен и объемов. В нашей системе эти данные генерируются случайно для демонстрации.

⏰ MarketResetCycle() - принудительный сброс
csharp
private IEnumerator MarketResetCycle()
{
    Debug.Log("[MarketController] Starting 15-minute market reset cycle");
    
    while (isTrading)
    {
        // Ждем 15 минут (900 секунд)
        yield return new WaitForSeconds(900f);
        
        if (isTrading)
        {
            Debug.Log("[MarketController] 15-minute cycle complete - resetting market");
            currentMarketId++;  // Новый ID для нового рынка
            
            // Останавливаем текущие обновления
            if (dataUpdateCoroutine != null)
            {
                StopCoroutine(dataUpdateCoroutine);
                dataUpdateCoroutine = null;
            }
            
            // Запускаем поиск нового рынка
            marketSearchCoroutine = StartCoroutine(FindAndSetupMarket());
        }
    }
}
Зачем нужен принудительный сброс?
Даже если что-то пошло не так (API не отвечает, логика определения времени сломалась), каждые 15 минут система гарантированно попытается найти новый рынок.

public void UpdateMarketInfo(PolymarketEvent market)
{
    try
    {
        current.eventId = market.id ?? "unknown";
        current.eventTitle = GetMarketDisplayName(market);

        current.sessionEndTime = startTime.AddMinutes(15);

🧮 Calculate15MinuteStartTime() - расчет времени начала
csharp
private DateTime Calculate15MinuteStartTime(DateTime currentTime)
{
    // Округляем вниз до ближайшего 15-минутного интервала
    int minutes = currentTime.Minute;      // Например: 10:07 → minutes = 7
    int remainder = minutes % 15;          // 7 % 15 = 7
    
    // Отнимаем остаток минут, секунд и миллисекунд
    DateTime startTime = currentTime.AddMinutes(-remainder)
                                      .AddSeconds(-currentTime.Second)
                                      .AddMilliseconds(-currentTime.Millisecond);
    
    return startTime;  // 10:07:30.500 → 10:00:00.000
}
Визуализация расчета:

text
Текущее время: 10:07:30
Шаг 1: minutes = 7
Шаг 2: remainder = 7 % 15 = 7
Шаг 3: 10:07:30 - 7 минут = 10:00:30
Шаг 4: 10:00:30 - 30 секунд = 10:00:00
Результат: 10:00:00
✅ IsMarketActive() - проверка активности рынка
csharp
public bool IsMarketActive()
{
    if (!isInitialized) return false;
    
    // Рынок активен только если с момента начала прошло меньше 15 минут
    DateTime now = DateTime.UtcNow;
    TimeSpan timeSinceStart = now - current.sessionStartTime;
    
    // Рынок длится 15 минут, но добавляем буфер в 30 секунд для плавного перехода
    bool isActive = timeSinceStart.TotalMinutes < 15.5 && GetSecondsRemaining() > 0;
    
    // Если прошло больше 16 минут, точно не активен
    if (timeSinceStart.TotalMinutes >= 16)
    {
        return false;
    }
    
    return isActive;
}
Почему 15.5 минут, а не 15?
Добавляем 30-секундный буфер для:

Неточности системных часов

Задержек сети

Плавного перехода к следующему рынку

💵 GenerateTestOrderbookData() - генерация тестовых данных
csharp
public void GenerateTestOrderbookData()
{
    try
    {
        // Случайный спред от 1% до 3%
        double spread = 0.01 + (random.NextDouble() * 0.02);
        
        // Цены для UP
        current.bidUp = Math.Round(0.5 - spread/2, 3);  // Цена покупки UP
        current.askUp = Math.Round(0.5 + spread/2, 3);  // Цена продажи UP
        
        // Цены для DOWN (дополняют UP до 1.0)
        current.bidDown = Math.Round(1 - current.askUp, 3);
        current.askDown = Math.Round(1 - current.bidUp, 3);
        
        current.lastUpdateTime = DateTime.UtcNow;
    }
    catch (Exception e)
    {
        Debug.LogError($"[MarketState] GenerateTestOrderbookData error: {e.Message}");
    }
}
Логика цен UP/DOWN:
На рынках "Up or Down" сумма вероятностей всегда равна 1 (100%):

Если цена UP = 0.52 (52% вероятность), то цена DOWN = 0.48 (48% вероятность)

Spread (спред) = askUp - bidUp = разница между ценой покупки и продажи

    }

    }

⏱️ Тайминг и циклы
Три параллельных таймера системы
Таймер	Интервал	Назначение	Где реализован
Рыночный таймер	15 минут	Длительность одного рынка	MarketState.IsMarketActive()
Таймер обновлений	1 секунда	Обновление цен и UI	DataUpdateLoop()
Таймер сброса	15 минут	Принудительный переход к новому рынку	MarketResetCycle()
Как работает синхронизация
csharp
// В MarketState:
public bool IsMarketActive()
{
    TimeSpan timeSinceStart = now - current.sessionStartTime;
    return timeSinceStart.TotalMinutes < 15.5;  // ← 15.5 минут с буфером
}

// В MarketController:
private IEnumerator MarketResetCycle()
{
    while (isTrading)
    {
        yield return new WaitForSeconds(900f);  // ← 900 секунд = 15 минут
        // Принудительный сброс
    }
}
Почему два таймера на 15 минут?

IsMarketActive() - логический таймер, проверяет фактическое время работы рынка

MarketResetCycle() - гарантийный таймер, сбрасывает систему даже если логика сломалась

private IEnumerator FindAndSetupMarket()
{
    // Ищем реальный рынок
    yield return StartCoroutine(apiManager.FindActive15MinuteBtcMarket(...));

    }
